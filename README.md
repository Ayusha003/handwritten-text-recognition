# Handwritten Text Recognition using Deep Learning

## Project Overview

This project is a deep learning-based handwritten text recognition system that converts handwritten text from images into digital, editable text.
The system uses image processing and OCR techniques to recognize handwritten content. The extracted text can then be processed further and converted into speech, making the application more interactive and accessible.
The project consists of a Python-based backend and a Flutter-based frontend.

## Key Features

- Recognizes handwritten text from images.
- Uses OCR and deep learning-based text recognition.
- Processes input images before text extraction.
- Provides a Flutter-based user interface.
- Python backend for handling text recognition and application logic.
- Text-to-Speech functionality for converting recognized text into audio.
- Includes chatbot/RAG-based functionality for interacting with the extracted text.
